# 基础刻度

通用取值方法。项目可以替换具体颜色和字体，但刻度的思路和下限不变。

## 字号

一个产品最多 6–8 个字号，全部写成变量，业务代码不写任意值。

| 用途 | 后台 / 工具类 | 内容 / 落地页 |
| --- | --- | --- |
| 辅助说明、表格副行、徽标 | 12 | 13–14 |
| 正文、表格主行 | 13–14 | 16–18 |
| 输入框、按钮 | 14 | 15–16 |
| 卡片 / 分组标题 | 15–16 | 18–20 |
| 页面标题 | 20–24 | 32–48 |
| 统计数字 | 24–28 | 按需 |

- 下限：任何文字 ≥ 12px；中文笔画密，小于 12px 基本靠猜。
- 相邻层级字号比约 1.125–1.25；标题和正文至少差两级。
- 字重最多三种（常规、中粗、粗）。
- 中文行高：界面短文本 1.4–1.5，连续阅读 1.6–1.75；英文正文 1.5。
- 字体：一个字体家族就够，靠字号、字重、颜色建立层级；第二种字体只在有明确分工时加入（例如等宽字体用于代码和 ID）。中文回退字体写全：苹方、冬青黑体、微软雅黑、思源黑体。

## 间距

以 4px 为单位：4、8、12、16、20、24、32、40、48、64。

- 组内间距 < 组间间距，至少差一档。
- 标题与下方内容的距离 < 标题与上方内容的距离。
- 控件内边距：小 8–12，常规 12–16。
- 卡片内边距 16–24；弹窗内容内边距 20–24。
- 文字不能贴边：任何有底色或边框的容器，文字距离边缘至少 8px。

## 尺寸

| 元素 | 高度 |
| --- | --- |
| 小按钮 / 分段控件 | 28–32 |
| 常规按钮 / 输入框 | 36–40 |
| 大按钮 | 44–48 |
| 表格行 | 44–56 |
| 最小点击区 | 24×24（移动端主要操作 44×44） |

## 圆角

按元素大小分档，同档统一：

| 元素 | 圆角 |
| --- | --- |
| 徽标、标签 | 全圆或 4–6 |
| 小按钮、分段项 | 6–8 |
| 按钮、输入框 | 8–10 |
| 卡片、面板 | 12–16 |
| 弹窗 | 14–18 |

大圆角不是越大越好：卡片圆角超过 20 会显得像玩具，也让所有卡片长得一样。

## 颜色

先定**角色**，再配具体颜色：

| 角色 | 说明 |
| --- | --- |
| 背景 / 表面 / 次级表面 | 3 层足够，层次靠明度差（约 2–4%）而不是阴影 |
| 主文字 / 次文字 / 弱文字 | 弱文字也要 ≥ 4.5:1 |
| 分隔线 / 强分隔线 | 装饰线可以很淡；控件边界要 ≥ 3:1 或有其他提示 |
| 强调色（实心、浅底、文字用） | 浅色背景上的强调色文字往往需要比按钮底色更深的一档才能达标 |
| 成功 / 警告 / 错误（各含浅底） | 语义固定，不挪作他用 |

- 中性色带一点主色的色相，比纯灰更耐看；但不要默认就选米色。
- 暗色主题单独调：不是简单反色。强调色提亮，阴影加深，图表颜色重新检查可分辨性。
- 同一颜色在深、浅两种背景上都要算对比度。深色区块（侧栏、深色头图）里的强调色文字用亮色版本。
- 状态不能只靠颜色：同时有文字或图标。

## 阴影与层级

- 层级主要靠明度差和细线；阴影只用于真正浮起来的东西（弹出层、弹窗、拖拽中的元素）。
- 细边框和大阴影不同时用在同一个元素上。
- 三档就够：卡片（几乎看不见）、弹出层、弹窗。

## 动效

| 场景 | 时长 |
| --- | --- |
| 按下、悬停、开关 | 100–150ms |
| 下拉、弹出层、提示 | 150–200ms |
| 弹窗、抽屉 | 200–300ms |

- 缓动：平滑减速，例如 `cubic-bezier(0.2, 0, 0, 1)`；不用回弹。
- 为状态服务：出现、消失、展开、位置变化，以及进行中、进度、数值变化、数据流向。状态类循环动画 1–2s 一个周期，任务结束即停。
- `prefers-reduced-motion: reduce` 时去掉位移和缩放，保留短暂淡入淡出或直接切换。
