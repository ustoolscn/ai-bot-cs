# ai-bot-cs 管理端的落地

只在 ai-bot-cs 项目里读。通用规则见 `SKILL.md`，这里只写本项目的设计决定、变量和组件。

## 一、设计决定（2026-11-23）

1. **界面是什么**：QQ 群客服的运营后台。每天要做的事：回复转人工的用户、审核学到的知识、管理群（成员、入群申请、禁言、发言审核、定时发送）。工具类界面，密度和效率优先。
2. **参照**：Linear 的列表密度和克制配色；飞书管理后台的左侧分组导航。
3. **记忆点**：吉祥物“小Q”。只出现在登录页和空状态，静止不动，不做漂浮、挥手动画。其余地方保持安静。
4. **主色**：取自 QQ 的蓝色，压深一档保证文字对比度。只用于主按钮、当前导航、链接和选中状态。
5. **这次要避开的 AI 味**（旧版命中过的）：奶油底 + 珊瑚渐变按钮；回弹缓动；漂浮等纯装饰动画；emoji 图标（🎙️）；卡片套卡片；同一个对象的功能分散在多个抽屉里。

## 二、设计变量（`frontend/src/styles/index.css` 的 `:root`）

| 角色 | 变量 | 值 |
| --- | --- | --- |
| 背景 / 表面 / 次级表面 | `--bg` `--surface` `--surface-2` `--surface-3` | `#f4f5f7` `#ffffff` `#f8f9fb` `#eef0f3` |
| 分隔线 | `--line` `--line-strong` | `#e5e7eb` `#d3d7de` |
| 文字 | `--text` `--text-2` `--muted` | `#1b2130` `#3f4757` `#646c7c` |
| 主色 | `--primary` `--primary-hover` `--primary-light` `--primary-text` | `#1f6bd1` `#1858ad` `#eaf2fc` `#1a5cb3` |
| 成功 / 警告 / 错误 | `--success` `--warning` `--danger`（各带 `-light`） | `#1d8052` `#a35f00` `#c93636` |

- 字号：12 / 13 / 14 / 16 / 20 / 24。正文 14，表格 13–14，任何文字不小于 12。
- 间距：4 的倍数。卡片内边距 16–20，页面边距 24–32。
- 圆角：标签 6，按钮输入框 8，面板 12，弹窗 14。
- 阴影：面板只用 1px 细线，不加阴影；只有弹出层、弹窗、抽屉有阴影。
- 动效：交互 120–200ms，`cubic-bezier(0.2, 0, 0, 1)`，不回弹；支持 `prefers-reduced-motion`。
- **状态动画（2026-11-23 用户要求）**：尽可能用动画展现状态。首页任务队列、正在回复、消息流水线、各环节用时、知识库进度、数字变化都要有对应动画；组件在 `frontend/src/components/fx/`。
- 字体：系统中文字体一套；ID、密钥、回调地址用等宽字体。

## 三、信息架构

导航按“每天处理 → 管群 → 配客服 → 知识 → 记录与系统”排：

| 分组 | 页面 |
| --- | --- |
| 工作台 | 今日概览、人工台 |
| QQ 群 | 群与会话、定时任务、黑名单 |
| AI 客服 | 机器人与客服、智能体与性格、通用设置 |
| 知识与记忆 | 知识库、用户记忆、效果评测 |
| 记录与系统 | 消息记录、模型、系统状态 |

**一个群的所有操作在一个页面里完成**：`/conversations/:id` 是群详情页，左侧分区：接待设置、成员与客服学习、群管理（只有群聊有）、发消息。列表页只负责找到这个群。

## 四、组件约定

- `PageHeader`：标题 + 一句说明 + 右侧操作；需要返回时传 `back`。
- `SectionCard`（`.panel`）：分组标题 + 一行说明 + 右侧操作，内容区不再套卡片。
- 列表页：`.page-fill` 让表格填满剩余高度，`el-table` 用 `height="100%"`，表头固定，只滚数据行。
- 状态：`StatusBadge`（圆点 + 文字），不只靠颜色。
- 空状态：`EmptyState`，写清为什么空、下一步做什么。
- 提示信息：一律 `ElMessage` toast；页面里不放按条件出现的红字和警示条。后端未连接时在侧栏底部显示固定的“示例数据”标记。
