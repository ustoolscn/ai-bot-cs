# 管理端改版方案（待确认）

日期：2026-11-23　范围：`frontend/` 全部页面，暂不需要新增后端接口。

---

## 一、现状问题（逐页看过之后的结论）

### 整体
1. **导航不好找**：顶部平铺 8 个入口，名字只有两个字（"学习""知识""模型"），看不出是干什么的；"消息记录"和"系统设置"根本不在导航里，只能靠搜索或右上角齿轮进入。
2. **不知道先干什么**：首页是一张很密的流水表，看不出"现在有几个人在等人工""有几条知识待审核""有没有出错"。
3. **字太小、太灰**：大量 11–12px 的浅灰字，表格和卡片里信息挤在一起，重点不突出，看久了累。
4. **页面大面积空白**：机器人、模型页只有两三张卡片，下面全是空白；人工台、学习页没数据时只有一个空盒子，没有告诉你下一步该做什么。
5. **报错打扰**：连不上服务时，红色提示条盖在顶部导航上，同一个错误重复出现。

### 各页
| 页面 | 问题 |
|---|---|
| 概览 | 左侧 228px 筛选栏常驻，挤占空间；流水表一排 9 列，很多"未知会话 / 空消息"；6 个指标同等大小，看不出主次 |
| 机器人 / 模型 | 卡片里是一串"名称：值"，信息密度低，操作按钮很小；"对话测试"藏在卡片底部 |
| 会话 | 表格能用，但配置抽屉很长，触发模式、模型、知识库、提示词混在一起 |
| 消息记录 | 点"详情"才能看处理链路；筛选项零散 |
| 智能体 | 5 个标签页，设置和"效果评测"混在一起；右上角一个"保存设置"管所有标签，切换标签后容易忘保存；"技能与工具"里有一句"修改后点右上角保存"；**先点"立即同步"再保存会报 400** |
| 知识学习 | 顶部 5 个数字卡片和下面 5 个标签重复 |
| 人工台 | 是一列卡片，不像工作台：不能左边看列表、右边回复 |
| 系统设置 | "本地文件存储"出现两次；连不上服务时整块表单变灰 |

## 二、改版方案

### 1. 导航：改成左侧分组导航
```
┌──────────────┬────────────────────────────────────────┐
│ AI 客服后台   │  页面标题                     [主要操作] │
│              │  一句话说明                              │
│ 工作台        │ ────────────────────────────────────── │
│  ◉ 今日概览   │                                        │
│  ◉ 人工台  3  │            页面内容                     │
│  ◉ 知识审核 12│                                        │
│ 运行记录      │                                        │
│  ◉ 消息记录   │                                        │
│  ◉ 群与会话   │                                        │
│ 客服配置      │                                        │
│  ◉ 智能体     │                                        │
│  ◉ 知识库     │                                        │
│  ◉ 效果评测   │                                        │
│ 接入设置      │                                        │
│  ◉ 机器人     │                                        │
│  ◉ 模型       │                                        │
│  ◉ 系统状态   │                                        │
│ ──────────── │                                        │
│  admin  ⌘K   │                                        │
└──────────────┴────────────────────────────────────────┘
```
- 按"每天要处理的 → 查记录 → 调客服 → 接入配置"分组，名字写全。
- 人工台、知识审核旁显示待处理数量（红点数字）。
- 可折叠成只显示图标；手机上变成抽屉。
- ⌘K 全局跳转保留，搜索范围覆盖所有页面。

### 2. 视觉方向：安静、清楚的工作台风格
- 背景浅暖灰，内容区白底，侧栏和内容区用细线分隔，不用重阴影。
- 主色从高饱和蓝换成更沉稳的靛蓝；成功/警告/失败颜色只用在状态上。
- 正文 14px，次要信息 13px，不再用 11px；灰字加深，保证看得清。
- 统一 8px 圆角、统一间距；页面头部统一为"标题 + 一句说明 + 右侧主要按钮"。
- 空状态都写清下一步，例如人工台为空时显示"暂时没有需要人工处理的用户，转人工规则在 智能体 → 学习与转人工"。
- 连不上服务时只在页面顶部显示一条可关闭的提示，不再重复弹出。

### 3. 各页调整
| 页面 | 调整 |
|---|---|
| **今日概览**（原概览） | 第一排"需要你处理"：待人工、待审核知识、失败消息、告警，点了直接跳过去。第二排 4 个核心指标（消息量、成功率、平均耗时、转人工率）。下面是"最近消息"简表（点开看链路）和"服务健康"（模型/知识库/队列状态）。筛选栏改为顶部一行：时间范围 + 机器人。 |
| **人工台** | 改成收件箱布局：左边工单列表（待处理/已结单），右边聊天记录 + 底部回复框，"结单并恢复机器人"放在右上角。 |
| **知识审核**（原学习） | 数字卡片和标签合并：标签本身带数量。待审核列表支持一键通过 / 驳回 / 编辑后通过。FAQ、知识缺口、反馈、用户记忆保留为标签。 |
| **消息记录** | 筛选合成一行；点任意一行从右侧滑出详情，直接展示处理链路时间线（接收 → 上下文 → 检索 → 模型 → 投递）和 Agent 详情。 |
| **群与会话** | 表格保留；配置抽屉分成"触发方式 / 回复模型 / 知识库 / 补充提示词"四段，每段有一句说明。 |
| **智能体** | 去掉顶部标签，改成左侧小目录（人设与风格、回复长度、上下文与记忆、辅助模型、学习与转人工、网站数据、技能与工具），一页滚动。有改动时底部出现固定的"有未保存的修改 · 放弃 / 保存"条，离开页面会提醒。"网站数据"里有未保存改动时，"立即同步"按钮置灰并提示"请先保存设置"，避免 400。 |
| **效果评测** | 从智能体里拆出来单独一页，左边用例、右边运行结果对比。 |
| **知识库** | 结构保留（左列表右详情），视觉统一；"检索测试"改成右侧抽屉，边测边看。 |
| **机器人 / 模型** | 卡片改为列表，每行显示名称、状态、关键参数和"测试/配置/复制回调"按钮；模型页把"对话模型 / Embedding"标签改成分组标题。 |
| **系统状态** | 合并重复的存储信息；分成"服务状态 / 任务队列 / 全局参数"三块。 |
| **登录页** | 简化为居中登录框，去掉大段宣传文字。 |

### 4. 删减 / 合并 / 新增
- **合并**：学习页的数字卡片并入标签；系统页重复的存储块合并。
- **拆出**：效果评测独立成页。
- **新增**：侧栏待办数字、概览"需要你处理"、智能体未保存提醒、"先保存再同步"引导、各空状态的下一步指引。
- **删除**：顶部导航栏、概览常驻筛选栏、右上角通知铃铛（改为侧栏数字）。

### 5. 后端
本次改版只用现有接口。侧栏数字用现有的人工台列表和学习统计接口取。如果后续想在一个接口里拿到所有待办数，再整理需求交给 Codex。
